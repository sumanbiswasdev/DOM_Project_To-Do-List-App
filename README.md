✅ To-Do List App A simple and clean To-Do List web application built using HTML, Tailwind CSS, and JavaScript. This project includes essential task-management features with a modern UI styled using Google Font – Poppins.

🚀 Features ➕ Add Task — Quickly add new tasks to your list ☑️ Delete Checked Tasks — Remove all completed tasks at once ❌ Delete Single Task — Remove individual tasks easily ✔️ Mark as Completed — Check off tasks as you finish them 🎨 Modern UI with Tailwind CSS — Fully responsive and clean design 🔤 Poppins Google Font — Smooth and minimal typography

🛠️ Tech Stack HTML5 Tailwind CSS JavaScript
